# 🏫 학교 유무선 네트워크 장애상담 지능형 챗봇 통합 플랫폼 (`H3lis/itzn_chat`)

> **초·중·고 학내망 장애 대응을 위한 생성형 AI 기반 상담·검색·보안·관리 올인원 통합 플랫폼**  
> **LangGraph 인지 대화 오케스트레이션** + **멀티모달 하이브리드 RAG** + **2단계 개인정보(PII) 비식별화** + **지능형 관리자 콘솔** + **온·오프라인 3-Tier 하이브리드 자립 체계**

## 🌟 프로젝트 개요 (Project Overview)

본 프로젝트는 전국 초·중·고등학교 및 교육 행정 기관에서 상시 발생하는 유무선 네트워크(스쿨넷 회선, 무선 AP, PoE 인젝터, 고정/DHCP IP 충돌, 스마트단말 MDM, 학내 전용망 NEIS/K-에듀파인, 통합관제시스템 등) 장애 및 기술 문의를 교직원이 스스로 진단하고 해결할 수 있도록 돕는 **생성형 AI 기반 차세대 통합 챗봇 플랫폼**입니다.

단순한 지식 검색(FAQ) 챗봇을 넘어, **13종 969페이지에 달하는 공공 교육 규정집·매뉴얼을 심층 추론하는 하이브리드 RAG 엔진**, 공공기관 보안 규정을 100% 준수하는 **2단계 개인정보(PII) 비식별화 시스템**, 현업 관리자를 위한 **5대 관리자 콘솔**, 그리고 네트워크 단절 사고 시에도 멈추지 않는 **완전 자립형 오프라인 클라이언트**까지 아우르는 엔터프라이즈급 아키텍처를 제공합니다.

## 🧩 5대 핵심 기술 구성요소 (Core Technical Pillars)

### 1. 🧠 Multi-Turn Cognitive Agent & LangGraph 오케스트레이션
- **14노드 메인 그래프 + 9노드 RAG 서브그래프**:
  단순한 1회성 프롬프트 질의응답이 아닌, 대화 문맥(Context)을 이해하고 사용자의 불완전한 질문에 대해 되묻거나(Clarification), 필요한 경우 단계를 순환(Cycle)하며 최적의 답변을 생성하는 상태 머신(StateGraph) 구조입니다.
- **계층형 의도 라우팅 (Hierarchical Routing)**:
  1. `Casual Greeting`: 일상 인사 및 챗봇 사용법 안내.
  2. `Scenario Branch`: 버튼 선택형 장애 점검 절차 (0ms).
  3. `FAQ Matcher`: 사전 승인된 고빈도 정답 1ms 내 즉시 응답 (코사인 유사도).
  4. `Hybrid RAG`: 규정집·매뉴얼 심층 검색 및 근거 기반 생성.
  5. `Web Grounding`: 교육청 최신 정책/공지사항 보조 검색.
- **실시간 SSE(Server-Sent Events) 스트리밍**:
  토큰 단위 응답 스트리밍뿐만 아니라 `[검색 중]`, `[리랭킹 중]`, `[근거 채점 중]` 등 RAG 내부 서브그래프의 추론 진행 상태를 사용자 화면에 실시간 시각화합니다.

### 2. 📚 Advanced Multimodal Hybrid RAG Engine (하이브리드 문서 검색 & 근거 생성)
- **13종 교육청 공공 매뉴얼 전수 인덱싱 (969페이지)**:
  학교 유무선 운영안내서, 무선랜 가이드라인, MDM 매뉴얼, 스쿨넷 서비스 가이드, 통합관제/이용관리 매뉴얼 전량 색인.
- **도표 및 조밀 표 텍스트화 (MinerU + VLM)**:
  복잡한 학교 네트워크 장비 포트 사양표나 결선도를 VLM과 MinerU 파이프라인으로 정밀 전사하여 시각 정보 오독률 **0%** 달성.
- **하이브리드 앙상블 검색 (Lexical + Dense)**:
  한국어 형태소 분석기(Kiwi) 기반 BM25Okapi 희소 검색과 Google `embeddinggemma` / BAAI `bge-m3` 밀집 벡터 검색을 RRF(Reciprocal Rank Fusion, k=60)로 결합.
- **고정밀 Cross-Encoder 리랭킹**:
  `bge-reranker-large` 모델을 통해 상위 20개 후보 청크의 의미적 적합도를 재평가하여 최상위 정밀도(**page_hit@3 0.774**) 달성.
- **결정론적 환각 가드 (Hallucination Guard & Controller CRAG)**:
  문서에 명시되지 않은 허위 조치법 생성을 차단하며, 근거가 불충분할 경우 거짓 정보를 지어내지 않고 정직하게 거절(Abstain)하거나 콜센터로 안전하게 폴백.
- **시각적 근거 매핑 (Bounding Box Highlighting)**:
  답변의 근거가 된 원본 PDF 페이지 번호와 해당 텍스트/표의 좌표(Bounding Box)를 추출하여 사용자 화면에 직관적인 뷰어로 제공.

### 3. 🛡️ 2-Stage Hybrid 개인정보(PII) 비식별화 및 보안 체계
- **개인정보보호법 완전 준수**:
  상담 과정에서 교직원이 실수로 입력할 수 있는 교원 실명, 학생 연락처, 학내망 고정 IP, 기기 MAC 주소, 카드/계좌번호, 주민번호 등을 실시간 감지하여 마스킹합니다.
- **2단계 하이브리드 파이프라인**:
  - **1단계 (고속 결정론적 정규식 필터)**: 주민번호, 휴대전화, IP/MAC, 교원 사번, 이메일 등을 0.005초 만에 100% 필터링.
  - **2단계 (문맥 인지형 sLLM 필터)**: 이름, 직책, 비정형 주소, 복합 계정 정보를 Google Gemini / Qwen2.5 경량 모델이 문맥을 추론하여 정밀 마스킹.
- **검증 성과 (학술 논문 수준)**:
  실제 학교 현장 상담 데이터 기반 **1,232건 벤치마크 전수 평가 결과, 재현율(Recall) 98.6% (171건 최소 미탐)**를 달성하였으며, SQLite `chat_history.db` 적재 전 100% 비식별화 무누락 보장.
- **적대적 프롬프트 주입 방어 (`safety_classifier.py`)**:
  BIP-IA (Indirect Prompt Injection Attack) 벤치마크 기반 가드를 적용하여 시스템 프롬프트 탈취, 가짜 지시문 삽입, 유해 발화를 원천 차단.

### 4. ⚙️ 지능형 관리자 통합 콘솔 (Admin Console - 5대 핵심 기능)
학교 전산 담당자 및 교육청 관제요원을 위한 통합 운영 환경입니다 (`/admin`):
1. **FAQ 관리 (CRUD 즉시 핫리로드)**:
   수동 임베딩 재생성 없이, 관리자 화면에서 질문/답변/키워드를 등록·수정·삭제하면 1ms 만에 챗봇 런타임에 즉각 반영.
2. **RAG 문서 전처리 및 메타데이터 뷰어**:
   업로드된 13개 원본 PDF의 페이지별 청크, LLM 추출 3줄 요약, 핵심 키워드, 메타데이터 부스팅 정보를 투명하게 열람.
3. **웹 검색 Grounding 실시간 On/Off 제어**:
   인터넷 최신 교육청 공지사항이나 실시간 IT 장애 속보를 반영할지 여부를 클릭 한 번으로 활성화/비활성화.
4. **8대 장애 시나리오 트리 비주얼 에디터**:
   버튼형 조치 절차의 노드 텍스트, 분기 옵션 칩, 다음 노드 연결 관계를 GUI 상에서 직관적으로 수정 및 배포.
5. **대화 이력 감사 & PII 비식별화 검증**:
   모든 상담 이력의 비식별화 마스킹 상태 검증, 사용자 긍정/부정(👍/👎) 피드백 통계 집계, 미해결 장애 분석.

### 5. 📶 온·오프라인 하이브리드 자립 및 3-Tier 동기화 체계
- **네트워크 단절 상황의 챗봇 딜레마 극복**:
  학교 내 네트워크가 마비되었을 때 웹 챗봇이 열리지 않는 역설을 해결하기 위해 개발된 완전 자립형 서브시스템.
- **608.49 KB 초경량 독립 실행 배포본 ([`학교챗봇_장애대응가이드_오프라인.html`](학교챗봇_장애대응가이드_오프라인.html))**:
  외부 CDN, 구글 폰트, 원격 서버 통신이 완전히 차단된 비행기 탑승 모드(AirPlane Mode)나 폐쇄망 PC에서도 더블클릭 시 0초 만에 기동하여 8대 장애 점검 가이드를 0ms에 제공.
- **하이브리드 3-Tier 자동 동기화**:
  - **Tier 1 (로컬 캐시)**: 브라우저 `localStorage`에서 이전 동기화 데이터 0ms 로드.
  - **Tier 2 (내장 폴백)**: 신규 PC 최초 기동 시 파일 내 인라인 기본 시나리오로 즉시 구동.
  - **Tier 3 (무중단 백그라운드 동기화)**: 온라인 복구 시 백엔드 ETag 버전 프로빙으로 최신 시나리오를 자동 갱신하고, 동일 출처 정책(SOP)을 극복하여 온·오프라인 상담 내역을 100% 양방향 병합.

## ⚡ 빠른 시작 및 구동 가이드 (Quick Start)

### 1. 로컬 풀스택 서버 원클릭 실행 (가장 추천)
로컬 PC에서 WAS, LangGraph 런타임, RAG 엔진, 웹 UI를 올인원으로 실행합니다:
1. 저장소 루트의 [`run_chatbot.bat`](run_chatbot.bat)을 더블클릭합니다.
   - 자동으로 파이썬 가상환경(`.venv`)을 감지하여 백엔드 서버를 시작합니다.
2. 웹 브라우저를 열고 접속합니다:
   - **사용자 상담 화면**: **`http://127.0.0.1:8002/`**
   - **관리자 통합 콘솔**: **`http://127.0.0.1:8002/admin`**

### 2. 오프라인 단독 클라이언트 실행 (무인터넷 0초 기동)
인터넷이 끊겨 브라우저 접속이 불가능한 긴급 상황에서 즉각 사용합니다:
1. 바탕화면의 [`학교챗봇_장애대응가이드_오프라인.html`](학교챗봇_장애대응가이드_오프라인.html)을 더블클릭합니다.
2. 외부 네트워크 연결 없이도 8대 장애 점검 가이드 및 과거 상담 내역이 즉시 제공됩니다.

### 3. 터미널(CLI) 수동 실행
```powershell
# 1) 가상환경 활성화 (PowerShell)
cd "c:\Users\ITZN\Desktop\챗봇"
.\.venv\Scripts\Activate.ps1

# 2) 챗봇 서버 기동 (포트 8002)
python -m chatbot_demo_v2 --port 8002

# 3) RAG 벡터 인덱스 재색인이 필요할 때
python -m chatbot_demo_v2.scripts.reindex
```

### 4. 클라우드 GPU(GCP L4) 인프라 연동 구동
초고속 추론(Gemini API 또는 로컬 vLLM/Ollama Qwen2.5) 및 BGE 리랭커 가속을 위해 GCP GPU VM을 활용할 수 있습니다:
- 상세 구축 가이드: [`GCP_GPU_연동_가이드.md`](GCP_GPU_연동_가이드.md) 및 [`GCP_VM_설정_및_연동_가이드.md`](GCP_VM_설정_및_연동_가이드.md) 참조.
