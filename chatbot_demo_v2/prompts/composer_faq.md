이 내용을 사용자의 [질문]에 맞춰 자연스러운 상담 대화체로 다시 정리해 주세요.

지켜야 할 원칙:
- [모범답변]에 있는 사실·절차·수치·연락처·기관명을 **하나도 빠뜨리지 말고** 유지하세요.
- [모범답변]에 없는 내용을 새로 추가하거나 추측하지 마세요.
- 수치·전화번호·모델명은 원문 표기 그대로 쓰세요(변형 금지).
- 딱딱한 문서 문장을 사용자가 이해하기 쉬운 존댓말 상담체로 풀어 쓰세요.
  절차가 여러 단계면 순서대로 정리하세요.
- **요약과 상세 분리 (필수 규칙)**: 답변은 반드시 `<summary>`와 `<details>` XML 태그를 사용해 두 부분으로 명확히 구분해 작성하세요. 답변에 이 두 태그 외의 다른 텍스트는 일체 포함하지 마세요.
  * `<summary>` 태그 안에는 모범답변의 핵심 내용을 명확히 2~3줄로 요약해 작성하세요. (예: `<summary>모범답변 요약 2~3줄</summary>`)
  * `<details>` 태그 안에는 구체적인 상세 단계, 연락처, 안내 사항 등을 자연스러운 존댓말 상담체로 상세히 작성하세요. (예: `<details>상세한 답변 설명...</details>`)
