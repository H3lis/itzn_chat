### [Slide 1] 표지 (Title)

* **부제목**: 오타·구어체도 찰떡같이 알아듣고, 거짓말(환각) 없이 100% 팩트만 전달하는 AI 상담관
* **발표자**: ITGN 인공지능 연구개발팀
* **슬라이드 레이아웃**: 밝고 신뢰감을 주는 디자인, 중앙에 핵심 가치 태그 `#친절한상담 #오타교정 #거짓말제로 #초고속응답`

> 🎙️ **발표 대본 (Speaker Script)**:
> "안녕하십니까. 오늘 발표드릴 프로젝트는 학교와 현장에서 네트워크나 와이파이가 안 될 때, 누구에게나 24시간 친절하고 정확하게 해결책을 알려주는 **'지능형 네트워크 장애상담 챗봇'**입니다. 기존 AI 챗봇들의 고질적인 문제였던 '엉뚱한 거짓말'과 '융통성 없는 검색'을 완벽히 해결한 똑똑한 상담 시스템입니다."

### [Slide 2] 현장의 문제점: 기존 AI 챗봇은 왜 답답했을까?
* **슬라이드 제목**: "와이파이가 안 돼요"라고 물었을 때 기존 챗봇의 한계
* **레이아웃**: 현장 사용자의 답답함 vs 기존 AI의 엉뚱한 답변 (대화창 비교)

```
[현장 사용자의 실제 질문]
👨‍🏫 "와파가 자꼬 끈켜서 수업을 몬하겠어요 ㅠㅠ"
👨‍🏫 "인터넷이 먹통입니다."
```
```
[기존 단순 챗봇의 문제점 3가지]
❌ 1. 융통성 부족 : 매뉴얼에 적힌 '공식 단어(무선 AP 접속 장애)'가 아니면 "검색 결과가 없습니다" 출력
❌ 2. 엉뚱한 넘겨짚기 : "인터넷이 안 된다"는 모호한 말에 마음대로 엉뚱한 장비 교체 매뉴얼을 안내
❌ 3. 그럴듯한 거짓말(환각) : 매뉴얼에 없는 가짜 전화번호나 잘못된 설정값을 진짜처럼 답변
```

* **핵심 메시지**:
  - 현장 사용자는 매뉴얼 용어가 아닌 **일상적인 말투, 오타, 줄임말**을 사용합니다.
  - 단순 검색형 AI는 질문을 제대로 이해하지 못해 엉뚱한 답변을 하거나 혼란을 초래합니다.

> 🎙️ **발표 대본 (Speaker Script)**:
> "선생님이나 행정 실무자분들이 급하게 장애가 발생했을 때 '무선랜 AP 신호 불량' 같은 전문 용어로 질문하지 않습니다. 보통 '와파가 자꾸 끊겨요'처럼 일상어로 말씀하시죠. 하지만 기존 챗봇은 단어가 조금만 틀려도 못 알아듣거나, 모호한 질문에 엉뚱한 답을 그럴듯하게 지어내는 문제가 있었습니다."

* **레이아웃**: 3대 목표 카드 (신뢰성 / 사용 편의성 / 경제성)

```
  ┌───────────────────────┐   ┌───────────────────────┐   ┌───────────────────────┐
  │  1. 거짓말 0% (신뢰성) │   │  2. 찰떡 이해 (편의성) │   │ 3. 비용·속도 (경제성) │
  ├───────────────────────┤   ├───────────────────────┤   ├───────────────────────┤
  │ 매뉴얼에 없는 숫자는   │   │ 오타·줄임말·모호한 말도│   │ 불필요한 연산을 줄여   │
  │ 단 1개도 말하지 않는   │   │ 전문 상담원처럼        │   │ 응답은 1.8배 빠르게,  │
  │ 철저한 팩트체크 시스템│   │ 알아듣고 되묻는 기능  │   │ 운영비는 40% 절감     │
```

### [Slide 4] 챗봇의 4단계 생각 과정 (전체 흐름)
* **슬라이드 제목**: 질문 접수부터 정답 전달까지의 4단계 스마트 파이프라인
* **레이아웃**: 직관적인 4단계 프로세스 카드

```mermaid
graph LR
    A["1단계: 질문 다듬기<br>(오타 교정·단어 정제)"] --> B["2단계: 맞춤 길 찾기<br>(FAQ/시나리오/전문검색)"]
    B --> C["3단계: 족집게 검색<br>(알짜 매뉴얼 찾기)"]
    C --> D["4단계: 팩트체크 & 답변<br>(거짓말 검증 후 전달)"]
```

1. **1단계 (질문 다듬기)**: 사용자의 오타와 거친 일상어를 깔끔한 표준 질문으로 변환합니다.
2. **2단계 (맞춤 길 찾기)**: 자주 묻는 질문(FAQ)은 0초 만에 즉답하고, 모호한 질문은 되물어봅니다.
3. **3단계 (족집게 검색)**: 방대한 기술 매뉴얼 중 진짜 정답이 적힌 페이지만 쏙쏙 골라냅니다.
4. **4단계 (팩트체크 & 답변)**: 친절한 상담원 말투로 요약하되, 원본 매뉴얼과 숫자를 대조해 거짓말을 완벽 차단합니다.

> 🎙️ **발표 대본 (Speaker Script)**:
> "우리 챗봇은 사람이 생각하는 과정과 똑같이 움직입니다. 질문이 들어오면 먼저 오타를 고치고(1단계), 자주 묻는 질문인지 전문 매뉴얼을 찾아야 하는지 길을 정합니다(2단계). 그 후 수백 페이지 매뉴얼에서 알짜 정답만 찾아내고(3단계), 최종적으로 팩트체크를 거쳐 친절한 답변을 화면에 띄워줍니다(4단계)."

### [Slide 5] 챗봇의 두뇌 구조 (LangGraph 상태 그래프)

### [Slide 7] [기술 1] 찰떡같이 알아듣는 '오타·구어체 교정기'
* **슬라이드 제목**: 오타와 줄임말도 표준 기술 용어로 자동 번역
* **레이아웃**: 전/후 비교 카드 (한글 자모 분해 & 동의어 사전)

```
[사용자 입력] "와파가 자꼬 끈켜요 ㅠㅠ"
      │
      ├─▶ [한글 자소 분해] '끈켜' ➔ 'ㄲ-ㅡ-ㄴ-ㅋ-ㅕ' ➔ '끊겨'로 오타 자동 수정
      ├─▶ [동의어 사전]   '와파' ➔ '무선랜(AP)' 표준 용어로 치환
      └─▶ [감정/불용어 필터] 'ㅠㅠ' 제거 및 문맥 정리
      │
[정제된 쿼리] "무선랜 AP 접속 끊김 조치 방법" ➔ 매뉴얼 100% 족집게 검색 성공!
```

* **사용자 경험의 비밀 (이원화 관리)**:
  - 화면 채팅창에는 사용자가 쓴 원래 글("와파가 자꼬 끈켜요")이 그대로 남아 친근함을 유지합니다.
  - 내부 검색 엔진에만 똑똑하게 변환된 표준 검색어를 전달합니다.

> 🎙️ **발표 대본 (Speaker Script)**:
> "첫 번째 차별화 기술은 '오타·구어체 교정기'입니다. 사용자가 '와파 끈켜요'라고 급하게 오타를 내도, 한글 자음과 모음을 쪼개어 '끊겨'로 바로잡고, '와파'를 매뉴얼 단어인 '무선랜 AP'로 번역하여 검색합니다. 덕분에 검색 성공률이 획기적으로 올라갑니다."

### [Slide 8] [기술 2] 의미와 키워드를 모두 잡는 '2중 그물망 검색'
* **슬라이드 제목**: 문맥으로 한 번, 고유 단어로 또 한 번 찾는 하이브리드 검색
* **레이아웃**: 2중 그물망(Dense + Sparse) 인포그래픽

```
                 [ 사용자의 질문 ]
                         │
         ┌───────────────┴───────────────┐
         ▼                               ▼
 [ 1. 의미 중심 검색 ]           [ 2. 단어 중심 검색 ]
 문맥과 뉘앙스가 비슷한         'SWIMS-01', '1899-0979' 등
 설명글을 넓게 찾음            정확한 모델명/에러코드를 콕 집음
         │                               │
         └───────────────┬───────────────┘
                         ▼
        [ 3. AI 2차 정밀 재정렬 (리랭킹) ]
     가장 정답에 가까운 알짜배기 페이지만 1순위로 배치!
```

* **효과**:
  - "인터넷이 불안정해요" 같은 뉘앙스 질문도 척척 찾고,
  - "에러코드 E-04" 같은 기계적인 고유 번호도 놓치지 않고 100% 찾아냅니다.

### [Slide 9] [기술 3] 알짜배기만 골라내는 '근거 3등급 분류'
* **슬라이드 제목**: 쓸데없는 잡음 문서는 버리고, 핵심 정답 페이지만 집중 요약
* **레이아웃**: 3등급(Primary/Supporting/Irrelevant) 필터링 다이어그램

```
[ 기존 방식의 문제 ]
수백 칸짜리 무관한 표(Table)가 검색 결과에 섞여 들어가 정답을 가려버림 (오답 원인 1위)
                         │
                         ▼
[ 우리 챗봇의 3등급 필터링 도입 ]
 🥇 1등급 (Primary)    : "이 페이지에 정답이 다 있다!" ➔ 본문 전체 집중 학습
 🥈 2등급 (Supporting) : "참고할 만한 보조 설명이다." ➔ 필요한 문장만 발췌
 ❌ 3등급 (Irrelevant) : "주제와 상관없는 잡음이다."   ➔ 가차 없이 버림 (오염 방지)
```

* **효과**: 엉뚱한 매뉴얼 표에 낚여서 이상한 답변을 하던 문제를 원천 해결했습니다.

### [Slide 10] [기술 4] 거짓말을 원천 차단하는 '100% 팩트체크 안전장치'
* **슬라이드 제목**: 매뉴얼에 없는 전화번호나 수치는 단 1개도 용납하지 않는 엄격한 검증
* **레이아웃**: 팩트체크 검증기 동작 흐름도

```
[AI가 작성한 초안] "장애 접수는 지원센터(02-123-4567)로 전화하세요."
                          │
                          ▼
            [ 🛡️ 팩트체크 가드레일 가동 ]
  "매뉴얼 원본에 '02-123-4567'이라는 번호가 실제로 있는가?"
                          │
                 ┌────────┴────────┐
                 ▼                 ▼
             [ 없음! ]          [ 있음! ]
         🚨 가짜 번호 감지!    ✅ 검증 통과 ➔ 사용자에게 전달
         초안 즉시 폐기하고
         매뉴얼 원문으로 복구
```

* **핵심 강점**:
  - LLM이 지어내는 환각(Hallucination) 수치를 0ms 만에 정확하게 잡아내어 **공공·교육 행정의 법적·기술적 신뢰성을 완벽하게 보장**합니다.

### [Slide 11] [기술 5] 마음대로 넘겨짚지 않는 '똑똑한 되묻기 (HITL)'
* **슬라이드 제목**: 모호한 질문에는 상황별 선택 버튼을 제시하는 친절한 상담

```
[상황] 사용자가 "인터넷이 안 돼요"라고만 쳤을 때

❌ [일반 챗봇] : 교실 문제인지 학교 전체 문제인지도 모르면서 아무 매뉴얼이나 읊음.
                  (열에 아홉은 엉뚱한 조치 안내)

⭕ [우리 챗봇] : "정확한 확인을 위해 상황을 선택해 주세요!" (버튼 제시)
                  ┌──────────────────────────────────────────────┐
                  │ [버튼 1] 우리 교실 와이파이만 안 돼요       │
                  │ [버튼 2] 학교 전체 행정망 인터넷이 먹통이에요│

                  └──────────────────────────────────────────────┘
```

* **효과**: 사용자가 버튼 하나만 누르면 딱 맞는 맞춤형 해결책으로 바로 안내합니다.

### [Slide 12] [기술 6] 친절한 상담관 말투 & 두괄식 답변 정책
* **슬라이드 제목**: 보기 편하고 이해하기 쉬운 깔끔한 답변 서식
* **레이아웃**: 답변 구조 비교 (줄글 장문 vs 두괄식 구조화)

* **상담 원칙**:
  1. **두괄식 결론**: 바쁜 현장 사용자를 위해 "무엇을 해야 하는지" 결론부터 제시.
  2. **단계별 번호 안내**: 1단계, 2단계 순서대로 따라 하기 쉽게 정리.
  3. **서버 재시작 없는 즉시 수정 (핫리로드)**: 상담 말투나 정책을 수정해도 시스템 중단 없이 0초 만에 반영.

* **철저한 보안/품질 게이트**:

  - 최신 기기 드라이버, 범용 IT 기술 등 매뉴얼에 없는 외부 정보만 **선별적으로 공인 웹 검색(Gemini Grounding)**을 통해 출처 링크와 함께 제공.

### [Slide 15] 무엇을 고쳐서 이렇게 빨라졌는가? (병목 해결 사례)
* **슬라이드 제목**: 성능을 갉아먹던 3대 숨은 원인 완벽 제거
* **레이아웃**: 3가지 개선 비하인드 스토리

2. **무관한 표(Table)의 컨텍스트 독점 해소**:
   - 관련 없는 198칸짜리 표가 AI 두뇌의 90%를 차지하던 문제를 ➔ **3등급 알짜배기 필터**로 해결.
3. **자주 묻는 질문(FAQ) 매칭 부활**:
   - 글자 하나만 달라도 못 찾던 융통성 없는 방식을 ➔ **문맥 유사도 매칭**으로 전면 개편.
